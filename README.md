## About Me

I'm **Padala Suraj**, a software developer focused on **full-stack development with React, Java, Spring Boot, and SQL**.

I enjoy connecting clean, responsive interfaces with well-structured APIs and relational databases. I'm continuously improving how I design, build, and debug applications from the frontend to the persistence layer.

- **Frontend:** Reusable React components, responsive layouts, and API integration.
- **Backend:** Java, Spring Boot, REST API design, and object-oriented programming.
- **Databases:** SQL, DBMS fundamentals, relational modeling, and query analysis.
- **Growth:** Data structures, algorithms, and meaningful open-source contributions.
